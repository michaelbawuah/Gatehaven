# Circuits to explore

- `starter.ghv`: two sources feed an AND gate. Remove either source, then advance
  two steps and inspect the output. The lower crossing wire carries a horizontal
  signal without energizing the vertical channel.
- `oscillator.ghv`: a NOR gate feeds its own input through a wire loop. Its output
  alternates on each simulation step.

All examples in this directory were authored for Gatehaven.

# Gatehaven

**Build circuits. Bring logic to life.**

Gatehaven is a digital logic sandbox being built in C++23. Connect wires,
combine logic gates, and step through a circuit to see how its signals change.

Development is at the foundation stage. Native desktop releases are planned
for Windows, macOS, and Linux. There is no finished release yet.

See [the roadmap](docs/roadmap.md) for the implementation order and
[the architecture](docs/architecture.md) for the core design.
